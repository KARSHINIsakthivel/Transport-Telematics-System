# 🚚 Transport Telematics System

## 📌 Overview

The **Transport Telematics System** is a web-based application designed to track, monitor, and manage vehicles in real time. It integrates GPS data, backend APIs, and a user-friendly frontend interface to provide efficient transport monitoring and decision-making.

---

## 🎯 Features

* 📍 Real-time vehicle tracking
* 🗺️ Map integration (Google Maps)
* 📡 Live location updates
* 🔐 User authentication
* 📊 Data storage and retrieval
* 🚨 Alerts and notifications

---

## 🛠️ Tech Stack

### Frontend

* HTML, CSS, JavaScript / React

### Backend

* Node.js with Express

### Database

* Firebase / MongoDB

## ⚙️ Installation & Setup

### 🔹 1. Clone the repository

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

---

### 🔹 2. Setup Backend

```
cd backend
npm install
npm start
```

Backend runs on:

```
http://localhost:5000
```

---

### 🔹 3. Setup Frontend

```
cd frontend
npm install
npm start
```

Frontend runs on:

```
http://localhost:3000
```

---

## 🔗 API Connection

Make sure your frontend connects to backend:

```
http://localhost:5000/api
```

For deployment, replace with your live backend URL.

---

## 🚀 Deployment (Render)

### Backend (Web Service)

* Root Directory: `backend`
* Build Command: `npm install`
* Start Command: `npm start`

### Frontend (Static Site)

* Root Directory: `frontend`
* Build Command: `npm install && npm run build`
* Publish Directory: `build`

---

## ⚠️ Common Issues

* ❌ npm not recognized → Install Node.js
* ❌ CORS error → Enable CORS in backend
* ❌ API not working → Check backend URL
